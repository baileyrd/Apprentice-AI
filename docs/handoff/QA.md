## Learners
- Q (2026-11-05, card #633): Does an online clone learner (discrete states, each tied to a look prototype learned by competitive learning; motor-conditioned transitions learned by a Hebbian rule on belief(t−1) × posterior(t), row-normalised; forward filtering with divisive normalisation; no backprop, no BPTT, no replay) count as local learning, so it can be #633's main-learner candidate without Q11? — A: Yes. Every weight change reads only its own pre- and post-synaptic activity (and its own row's sum for normalisation), with no error carried back through units or time; that is "local weight updates" under D2, reaffirmed by D33. Q11/D35 only arise if a non-local learner would become the main one. Becoming a default anywhere is still a D1 change.
- Q (2026-11-05, card #633): Does anything in the record say #633 must start from the GRU baseline or from e-prop variants, or limit built-in state counts? — A: No. Card #633 lists two open ideas (an innate place sense; a local rule carrying credit across units over time) and only rules out backprop as main learner (D2, D33). D8 covers the built-in time counter and labelled moves and squares, not state counts; the clone count rule is in D36. Nano chose "no innate place sense; find a learner that keeps state" (docs/facing/README.md § GRU ceiling check), which this fits.
- Q (2026-11-05, card #633): Is "view-change credit" local under D2/D33? Rule: a transition where the view stays the same is learned at once (Hebbian, as proposed); a transition where the view changes leaves a tag on each synapse i→j (belief in i before × T_ij, j a clone of the new view), held until the view next changes; then each clone j forecasts that change from its own outgoing weights (Σ_k T[m]_jk · [k shows the new view]) and the tag becomes a weight change in proportion to that forecast (normalised). Fixed-lag smoothing (backward messages through T over L steps) was the alternative. — A: View-change credit is local: a synapse-local eligibility tag times a signal the unit computes from its own outgoing weights and what it now sees, with nothing passed back through other units or over later steps. It has the same three-factor shape as e-prop, which docs/facing § Step 2 rules "local in space and time" (trace × the unit's own signal through its own weights). Fixed-lag smoothing is not local: it is the "credit that flows through other units over later steps" that docs/facing § The facing track stops here (item 4) says local learners lack. Using it as the main learner would be Q11, Nano's call (D35). Conditions: "k shows the new view" must come from k's own look match, and normalisation stays per unit or per row. Locality is settled here; changing the learner Nano approved is a separate question.
